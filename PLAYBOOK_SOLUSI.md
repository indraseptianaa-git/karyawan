## ATURAN MUTLAK PLAYBOOK-FIRST & CONFIDENCE-BASED ROUTING (ANTI-REGRESI)
1. **Urutan Eksekusi Berbasis Rating (Confidence-Based Routing)**:
   - Setiap masalah/kasus memiliki daftar solusi bertingkat (`v1`, `v2`, `v3`, dst.).
   - Antigravity IDE **WAJIB 100% menjalankan solusi yang memiliki Rating Persentase Keberhasilan (% Success Rate) Tertinggi dan Waktu Terakhir Sukses Paling Baru (Prioritas #1 Utama)**.
   - Dilarang keras melakukan analisis dari nol atau bereksperimen liar sebelum solusi dengan rating tertinggi dicoba.
2. **SOP Penanganan Kendala (Fallback Chain)**:
   - Jika Prioritas #1 gagal, sistem **OTOMATIS BERALIH (FALLBACK)** ke solusi Prioritas #2 (Cadangan).
   - Solusi lama **DILARANG DIHAPUS ATAU DITIMPA**. Solusi lama tetap disimpan sebagai arsip/cadangan historis.
3. **Protokol Solusi Baru (Jika Seluruh Resep Playbook Gagal)**:
   - Hanya jika semua solusi terdaftar gagal, AI melakukan analisa mendalam untuk merumuskan solusi baru (`v_baru`).
4. **Hukum Besi Kekebalan Playbook (Read-Only Blueprint)**:
   - File ini adalah Dokumen Statis Cetak Biru. AI DILARANG KERAS mengedit, menimpa, atau mencatat status harian ke file ini saat proses kerja.
   - Status produksi harian HANYA boleh dicatat di `data/local-db.json`.
   - File ini diawasi oleh Git Protected Branch di GitHub `indraseptianaa/Karyawan` dan hanya Bos Indra via GitHub Approve/Merge yang berhak mengesahkan revisi.
